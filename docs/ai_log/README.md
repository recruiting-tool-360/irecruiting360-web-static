# AI 编码详细日志

详细日志写入 `docs/ai_log/<owner>/`，文件名为 `YYYY-MM-DD-NNN-slug.md`。序号按维护者和当天递增；写入前扫描已有文件，不覆盖。

摘要维护在 `docs/ai-log/<owner>/ai-log.md`，每条摘要链接到对应的详细日志。摘要结论必须与详细日志一致。

只记录可审计事实：

- 读取过的代码、配置、文档和关键结论。
- 实际改动、验证命令、结果和未验证范围。
- 明确的设计建议、待确认项和遗留风险。

不得记录内部思维链、完整提示词、密码、Token、密钥、证书内容、真实生产地址、个人敏感数据或候选人真实信息。

## 模板

```markdown
# YYYY-MM-DD AI 编码日志：任务名称

## 任务

目标与范围。

## 依据

核对的文件、代码与关键结论。

## 改动

实际文件与原因。

## 验证

执行命令、结果、告警和未验证范围。

## 遗留

待确认项与后续动作。
```
