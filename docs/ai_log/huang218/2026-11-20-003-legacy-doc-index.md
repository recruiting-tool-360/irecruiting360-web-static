# 2026-11-20 AI 编码日志：旧文档总索引

## 任务

## 依据

- `git status --short --branch`：确认当前分支和已有初始化改动，未重置任何未提交内容。
- `AGENTS.md`、`docs/README.md`：确认项目模块、文档冲突规则和维护者目录契约。
- `find docs -maxdepth 1 -type f -name '*.md'`：确认根目录共有 26 份旧专题文档，另有文档入口和本索引。
- 原有专题文档标题、状态说明和相互引用：用于区分当前参考、历史版本、草案、待评审、实测样本、执行物和排期估算。
- 现有代码、配置和接口优先于文档；索引中的状态不表示对应方案已经实施。
